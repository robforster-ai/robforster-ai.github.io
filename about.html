// PRINCIPLES

№01

The bug is in the org-chart.

Most "AI failures" aren't model failures. They're ownership failures. Fix the operating model before fine-tuning anything.

№02

Pilots ≠ demos.

If a pilot doesn't have a path to production on day one, it's a demo dressed up. Don't run demos with pilot budgets.

№03

Measurement is governance.

If you can't see what the model is doing in production, you don't have a model in production — you have an exposure.
